Enhance the MVP with quality-of-life improvements, expanded tools, and deeper AI capabilities.

- Organize by theme
- Quick add from imports

### 2. Color Tools
- Palette creation
- Palette extraction from images
- Seasonal palette integration

### 3. Technique Helpers
- Brushstroke guides
- Layering tips
- Material usage suggestions

### 4. Enhanced Import/Export
- Batch import
- Better metadata stripping
- Export presets

### 5. AI Assistant (Expanded)
- Technique explanations
- Material recommendations
- Project planning suggestions
- Voice-first interactions

### 6. UI Polish
- Smoother transitions
- Better density modes
- Improved accessibility

## Success Criteria
- Artists feel increased fluidity
- AI becomes more helpful without overstepping
- Boards and palettes become core workflow tools
