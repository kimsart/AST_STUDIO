# Roadmap — V2 (Major Expansion)

## Purpose
Introduce social systems, advanced AI workflows, and community features while maintaining strict safety boundaries.

## Major Features

### 1. Social — Main
- Public posts
- Technique discussions
- Community challenges
- Trend engine
- Inspiration boards (public)

### 2. Social — Minors (Protected)
- Parent approval
- Skill-level rooms (Beginner, Intermediate, Advanced)
- Rotating themed rooms
- Safe upload system
- Showcase wall
- Strict AI moderation

### 3. AI Parent Moderator
- Topic-only responses
- Non-conversational tone
- Redirect patterns
- Trend filtering
- Safety enforcement
- Parent dashboard integration

### 4. Parent Dashboard
- Approve/deny access
- Activity summaries
- Moderation logs
- Prompt history
- Permission controls

### 5. Advanced AI Tools
- Multi-step technique lessons
- Project planning assistance
- Material optimization
- Style studies

## Dependencies
- V1 + V1.1 must be stable
- Moderation tools must be complete
- Safe Mode must be fully implemented

## Success Criteria
- Safe, thriving community
- Zero parasocial drift
- High parent trust
- Artists benefit from trends and challenges
