# Roadmap — V1 (MVP)

## Purpose
Define the smallest version of AST Studio that still feels complete, coherent, and useful to artists.

## Core Deliverables

### 1. Studio Organization System
- Drawers (supplies)
- Cabinets (projects)
- Flat files (loose paper)
- Shelves (references)
- Worktables (active work)
- Boards (inspiration)

### 2. Supply Tracking
- Add/edit/delete supplies
- Categories (brushes, paints, surfaces, etc.)
- Inventory counts
- Expiration tracking
- Basic reminders

### 3. Project Management
- Create/manage projects
- Project states (idea → active → archived)
- Material lists per project
- Notes and references

### 4. Measurement Tools
- Canvas sizes
- Ratios
- Conversions
- Presets

### 5. Import/Export Basics
- Import photos/scans
- Export project snapshots
- Save references to shelves

### 6. AI Assistant (Core)
- Open drawers/cabinets
- Find supplies
- Show project materials
- Clear worktable
- Basic prompt understanding

### 7. UI System (Complete)
- Bento grid
- Interaction patterns
- Component library
- Color system
- Layout rules
- Textures & materials

### 8. Safe Mode (Global)
- Reduced motion
- High contrast
- Privacy-first defaults

## Out of Scope for V1
- Social systems
- Trend engine
- Parent dashboard
- Advanced AI workflows
- Community features

## Success Criteria
- Artists can manage supplies and projects
- Worktable feels intuitive and tactile
- AI assistant improves workflow
- UI feels cohesive and studio-native
