# Roadmap Overview

## Purpose
Provide a high-level strategic view of AST Studio's development path, outlining major phases, priorities, and long-term vision.

## Product Themes
- Artist empowerment
- Studio-native workflows
- Safety-first design
- Modular, scalable architecture
- AI-assisted creativity
- Community building (with strict boundaries)
- Accessibility and inclusivity

## Roadmap Structure
- **V1 (MVP)** — Core studio tools and foundational UI
- **V1.1** — Quality-of-life improvements and expanded tools
- **V2** — Social systems, community features, advanced AI
- **Future** — Long-term vision and experimental ideas

## Guiding Principles
- Ship the smallest complete version first
- Build modularly so features can evolve independently
- Prioritize safety and privacy at every layer
- Maintain clarity, simplicity, and studio-native metaphors
- Ensure all AI behavior is transparent and bounded

## Dependencies
- UI System must be stable before V1
- AI Assistant must be functional before V2
- Social systems depend on moderation tools
- Minors' social depends on parent dashboard + AI Parent Moderator

## Success Metrics
- Artist satisfaction
- Workflow efficiency
- Safety compliance
- Community engagement (post-V2)
- Accessibility adoption
